# Insurance Premium Prediction API

A FastAPI-based Machine Learning API that predicts insurance premium categories based on user health, lifestyle, and demographic data.

## Features

- ✅ Predicts insurance premium category using scikit-learn model
- ✅ BMI calculation, lifestyle risk assessment, age grouping, and city tier classification
- ✅ RESTful API with proper input validation using Pydantic
- ✅ Fast and lightweight deployment-ready

## Tech Stack

- **Backend**: FastAPI
- **ML Model**: scikit-learn (with pandas preprocessing)
- **Model Persistence**: Pickle / Joblib
- **Validation**: Pydantic v2
